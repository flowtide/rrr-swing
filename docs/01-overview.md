# rrr-swing 개요 — 목적과 개념 한눈에

> 이 문서가 상위다. 세션 계약(`AGENTS.md`)과 코드는 이 문서를 따른다. (경로는 `rrr-swing` 작업 디렉터리 기준)

## 1. 목적 — 한 줄

**rrr-swing 은 한 계좌를 맡은 전문 스윙 트레이더다.** 시장의 흐름과 종목의 이야기를 알고, 자기 판단으로 베팅하고, 결과를 기록하고, 배운다.
규칙표를 실행하는 기계가 아니다. 규칙은 트레이더가 스스로 세우고 고친다.

## 2. 네 주체와 원칙

```
  운영자(사람) ─── 콘솔 대화 · 손절 협의 · 주간 미팅 · 급정지 ───┐
                                                                 ▼
  공급자 rrr ── 이벤트·시세·수급 ──▶  트레이더(LLM)  ──▶ 코드(장부 · 사후 보고)  ──▶ 키움 계좌
                 (증거만)               (판단 전부)          (판단 없음)
```

| 주체 | 하는 일 | 하지 않는 일 |
|---|---|---|
| **트레이더(LLM)** | 상황 인식, 가설, 진입·청산·수량·시점, 한도와 손절 정책, 기록, 복기 | MCP로 주문 실행 |
| **코드** | 이벤트 전달, 장부 기록, 사후 보고, 급정지(gw 키 비활성화 D18) 집행 | 가격·수급을 이유로 판단을 막거나 바꾸는 일 |
| **운영자(사람)** | 사후 감독, 손절 협의, 주간 미팅에서 전략 변경 합의, 급정지 소유 | 건별 승인 |
| **공급자 rrr** | 5분봉 지지/저항 이벤트 6종 + heartbeat, macro, `/context`·`/flow` 측정값 | 추천·점수·주문 |
