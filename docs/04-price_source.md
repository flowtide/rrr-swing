# Cookbook — 현재가 소스 결정 (폴백 체인)

rrr-trading2 `docs/04-price_source.md` 를 이식했다. 바뀐 것: 호스트는 `config.gw.base_url`, 주기 조회 문구 삭제(이 세션은 폴링하지 않고 배달된 이벤트 wake 시 조회), 보류 표기는 `decision(hold)` + 재검토 시각, 주문 거래소는 `SOR` 고정.

현재가는 **세션(개장 전 / 정규장 / 애프터)·거래소(KRX / NXT)에 따라 신뢰도가 다르다.** 판단·평가손익 계산에 쓰는 현재가는 아래 분석용 폴백 체인으로 얻는다. 분석 가격과 주문 가격은 별도 계약이다. **주문 직전에는 폴백 결과를 재사용하지 말고 브로커 호가를 즉시 다시 읽는다.**

## 적용 지점

- 이벤트 wake 시 decision packet 의 현재가 확인
- 보유 종목 평가손익의 참고값(회계의 20:30 마크는 종가 기준이며 별도)
- 주문 직전 가격·호가 검증

## 폴백 체인 (1 → 2 → 3, 상위 실패 시에만 하위 사용)

### 1차: `/context` 의 `quote.price`

```
GET {gw.base_url}/api/stocks/{6자리코드}/context
```

- 세션·거래소를 공급자가 통합 처리하므로 분석용 1차 증거다. S/R·VWAP·수급·ATR 도 함께 온다. 스펙: rrr-gw-skills `stock_context_llm_spec.md`.
- **측정 전용** — 해석 필드를 매매 룰로 직역하지 않는다.
- 응답의 `created_at` 은 서버 조립 시각이다. quote 의 원천 `as_of`·`age_sec` 을 보증하지 않으므로 **fresh 하다는 증거나 주문 가격으로 쓰지 않는다.**

### 2차: 브로커 실시간 호가 — `{코드}_AL` (NXT 포함)

- `/context` 실패 시 분석용 폴백이며, 주문 직전에는 `/context` 성공 여부와 무관하게 다시 쓴다.
- `_AL` 접미사 = NXT 실시간(프리마켓 08:00–09:00·애프터마켓 포함). 최우선매수/최우선매도 호가로 현재가를 근사한다.
- **`_AL` 은 조회 전용** — 주문에 쓰면 종목없음 오류. 주문은 **순수 6자리 코드 + `dmst_stex_tp="SOR"`** 로 넣는다(거래소 고정).
- `_AL` 조회 값에는 부호(`+`/`-`) 문자열이 붙을 수 있다 — **절대값 정규화 후 사용**(계산 스크립트의 `_px_abs` 와 같은 규칙).

### 3차: 브로커 기본 정보의 `cur_prc` — 최후 수단

- **정규장 09:00–15:30 만.**
- 개장 전(`open_pric=0`·`trde_qty=0`)에는 전일종가 stale 값이라 판단에 쓰면 오판한다. 계좌 평가 응답의 `cur_prc` 도 같은 함정 → **개장 전 평가손익의 현재가로 신뢰하지 않는다.**

## 주문 직전 가격 계약

1. 결정(`decision`)과 현재 세션을 다시 확인한다. **거래소는 고르지 않는다** — `dmst_stex_tp="SOR"` 고정이며 라우팅은 브로커가 한다.
2. 브로커 호가를 새로 조회한다. NXT 호가가 유효한 종목은 `{코드}_AL` 의 최우선 호가를 쓰되 `_AL` 자체는 주문 코드에 넣지 않는다. KRX 에서만 거래되는 종목은 KRX 정규장 유효 호가만 쓴다. 이 구분은 **어느 호가를 믿을지**의 문제이고 주문 거래소와는 무관하다.
3. 매도호가가 해당 lot 의 floor 미만이거나 호가가 0·누락·stale 이면 주문하지 않고 `decision(hold)` 에 재검토 시각을 붙인다. 매수도 유효 호가와 최신 주문가능금액을 확보하지 못하면 같다.
4. 주문은 순수 6자리 코드 + `dmst_stex_tp="SOR"` + 지정가만 쓴다. 시장가는 쓰지 않는다. 규칙에 의한 취소가 없으면 20:00 장 종료 시 자동 소멸하므로 마감 전 취소 작업을 두지 않는다.
5. 주문 제출 뒤에는 응답 성공 여부만 믿지 않고 미체결·당일 체결로 접수 여부를 대사한다(submit-and-reconcile). 대사 후 `bin/order.py` 로 원장 `order` 기록 및 사후 보고를 남긴다.

## 사고 사례 (근거)

- 2026-07-13 라이브: 개장 전 KRX 가 전일종가를 stale 로 표시해 평가손익이 허수로 나옴. 펩트론(`087010`): KRX 표시 `159,300` vs 실제 NXT `116,200`. 이 사고 이후 위 폴백 체인이 표준이 되었다.

| 순위 | 소스 | 신뢰 구간 | 주의 |
|---|---|---|---|
| 1 | `/context` `quote.price` | 전 세션 분석 | 측정 전용, `created_at` 은 quote freshness 아님 |
